## 1. 개요

**셀 구조** 기능은 데이터 테이블에서 하나의 셀에 **여러 컬럼의 값을 조합해서 표시**하거나, **컬럼 헤더 이름을 다르게 표시**할 수 있는 기능입니다.

설정한 구조는 앱을 재시작해도 유지되며, JSON 파일로 내보내고 다른 환경에 가져올 수 있습니다.

---

## 2. 셀 구조란?

셀 구조를 사용하면 다음 세 가지를 할 수 있습니다.

### ① 여러 컬럼을 하나의 셀에 합쳐서 표시

`price`, `qty`, `unit` 컬럼이 각각 존재할 때, `price` 위치에 세 컬럼을 모두 표시할 수 있습니다.

```
┌─────────────────┐
│ price           │  ← 헤더 (또는 사용자 정의 이름)
├─────────────────┤
│ 15,000          │  ← price 값
│ → 수량: 40      │  ← "→ 수량: " + qty 값
│ EA              │  ← unit 값
└─────────────────┘
```

흡수된 컬럼(`qty`, `unit`)은 표시 모드에서 별도 컬럼으로 나타나지 않고 숨겨집니다.

### ② 컬럼 헤더 이름 변경

`customer_name` 컬럼의 헤더를 **"고객명"** 으로 표시합니다. 데이터는 그대로이고 헤더만 바뀝니다.

### ③ 값 앞에 텍스트 붙이기

`discount` 컬럼 값 앞에 `"-"` 를 붙여 `- 5,000` 처럼 표시합니다.

---

## 3. 다이얼로그 열기

데이터 편집 화면에서 **컬럼 헤더를 우클릭** 하거나 헤더 메뉴를 통해 **"셀 구조 설정"** 을 선택합니다.

> 헤더에서 열면 해당 컬럼의 편집 화면으로 바로 진입합니다.

---

## 4. 컬럼 목록 화면

다이얼로그를 열면 현재 테이블의 **모든 컬럼**이 하나의 목록으로 표시됩니다.

```
셀 구조 관리
orders                          ← 현재 테이블 이름
────────────────────────────────────────────
[내보내기]  [가져오기]             ⋮
────────────────────────────────────────────
■ 고객명  ← customer_id          ← 구조 있음 (파란 바)
  price · → 수량: qty · unit
  숨김: qty, unit

■ memo                           ← 구조 있음 (단일 컬럼)
  memo

○ customer_id   구조 없음 — 탭하여 추가   ← 구조 없음 (회색 바)
○ created_at    구조 없음 — 탭하여 추가
────────────────────────────────────────────
                              [닫기]
```

| 표시 | 의미 |
|------|------|
| **파란 세로 바** | 구조가 설정된 컬럼 |
| **회색 세로 바** | 구조가 없는 컬럼 |
| `숨김: ...` | 이 컬럼 위치로 흡수되어 숨겨진 컬럼들 |

- **구조가 있는 컬럼**: 아무 곳이나 탭하면 편집 화면으로 이동합니다.
- **구조가 없는 컬럼**: 탭하면 해당 컬럼으로 새 구조 추가 화면이 열립니다.
- 구조가 설정된 컬럼이 위쪽, 없는 컬럼이 아래쪽에 정렬됩니다.

### ⋮ 메뉴

오른쪽 상단의 `⋮` 버튼을 누르면 다음 항목이 나타납니다.

| 항목 | 설명 |
|------|------|
| **전체 삭제** | 현재 테이블의 모든 셀 구조를 삭제합니다 |

## 5. 구조 추가 및 수정

컬럼을 탭하면 편집 화면으로 진입합니다. 상단에 컬럼명이 서브타이틀로 표시됩니다.

```
← 새 구조 추가 / 구조 수정
   customer_id              ← 메인 컬럼명
────────────────────────────
헤더 표시 이름 (선택)
[___________________________]

  직접 구성 ⚙   예시로 입력 ✨
────────────────────────────
[편집 영역]

미리보기
┌────────────────┐
│ 헤더이름       │
├────────────────┤
│ 줄1 내용       │
│ 줄2 내용       │
└────────────────┘
────────────────────────────
            [취소]  [저장]
```

---

### 5.1 직접 구성 탭

각 줄에 **앞 텍스트**와 **컬럼**을 직접 지정합니다.

```
앞 텍스트        컬럼
[        ]  [price        ▼]  [−]
[→ 수량: ]  [qty          ▼]  [−]
[        ]  [unit         ▼]  [−]

[+ 줄 추가]
```

| 항목 | 설명 |
|------|------|
| **앞 텍스트** | 값 앞에 붙일 문자열. 비워두면 값만 표시됩니다. |
| **컬럼** | 이 줄에 표시할 컬럼을 선택합니다. |
| **드래그 핸들** (왼쪽 아이콘) | 드래그해서 줄 순서를 바꿉니다. |
| **− 버튼** | 해당 줄을 삭제합니다. (최소 1줄 유지) |
| **+ 줄 추가** | 새 줄을 추가합니다. |

> **메인 컬럼**: 첫 번째 줄의 컬럼이 메인 컬럼으로 취급됩니다. 이 컬럼의 위치에 구조화된 셀이 표시되고, 다른 컬럼들은 숨겨집니다.

---

### 5.2 예시로 입력 탭

실제 데이터 샘플을 붙여넣으면 구조를 **자동으로 추론**합니다.

```
① 샘플 값 입력          →    ② 원하는 출력 형태
┌──────────────────┐         ┌──────────────────┐
│ price = 15000    │   →     │ 15000            │
│ qty = 40         │         │ → 수량: 40       │
│ unit = EA        │         │ EA               │
└──────────────────┘         └──────────────────┘
```

**① 샘플 값 입력** 형식:
```
컬럼명 = 값
컬럼명: 값
```

**추론 결과** 섹션에서 추론된 각 줄의 **앞 텍스트**와 **컬럼**을 확인하고 수정할 수 있습니다.

| 상태 | 표시 |
|------|------|
| 정상 추론 | 흰 배경 |
| 추론 실패 | 주황 배경 → 드롭다운으로 컬럼 직접 지정 |

추론 후 하단에서 **메인 컬럼**을 선택합니다. 이 컬럼의 위치에 구조화된 셀이 표시됩니다.

---

### 5.3 헤더 표시 이름

편집 화면 최상단 필드에 이름을 입력하면 **헤더(컬럼 제목)** 가 해당 이름으로 표시됩니다.

| 상황 | 헤더 표시 |
|------|-----------|
| 비워둠 | 원래 컬럼명 그대로 |
| 이름 입력 | 입력한 이름으로 표시 (`← 원래컬럼명` 으로 원본 표기) |

한글, 영어, 특수문자 모두 사용 가능합니다.

**예시**:
- `customer_name` 컬럼에 표시 이름 `"고객명"` 입력
- 헤더: **고객명** ← `customer_name`

---

### 5.4 미리보기

편집 화면 하단에 **실시간 미리보기**가 표시됩니다.

```
미리보기
┌─────────────────────┐
│ 고객명              │  ← 헤더
├─────────────────────┤
│ customer_name       │  ← 줄 1 (앞 텍스트 없음)
│ → 수량: qty         │  ← 줄 2 (앞 텍스트 "→ 수량: ")
└─────────────────────┘
```

> 미리보기의 셀 내용은 실제 값 대신 컬럼명을 자리표시자로 사용합니다.

저장하지 않고 **취소**를 누르면 변경 사항이 적용되지 않습니다.

---

## 6. 구조 삭제

### 개별 삭제

목록 화면에서 구조가 있는 컬럼 항목의 **휴지통 아이콘**을 탭합니다.

### 전체 삭제

`⋮` → **전체 삭제**를 선택합니다. 확인 다이얼로그 후 현재 테이블의 모든 구조가 삭제됩니다.

## 7. 내보내기

목록 화면의 **[내보내기]** 버튼을 누르면 범위를 선택하는 다이얼로그가 표시됩니다.

```
내보내기
  ◉ 현재 테이블
    orders  ·  3개 구조
  ○ 전체 서버
    모든 서버·테이블의 설정을 하나의 파일로

                    [취소]  [다음]
```

---

### 7.1 현재 테이블 내보내기

**[다음]** 을 누르면 메타데이터 입력 다이얼로그가 열립니다.

| 필드 | 필수 | 설명 |
|------|------|------|
| **이름** | ✅ | 파일 식별용 이름 (예: `고객 테이블 뷰 설정`) |
| **설명** | ❌ | 용도나 특이사항 메모 |
| **버전** | ❌ | 기본값 `1.0` |

저장 시 파일명은 `cell_structures_{테이블명}.json` 으로 제안됩니다.

**파일 구조**:
```json
{
  "metadata": {
    "name": "고객 테이블 뷰 설정",
    "description": "영업팀용 컬럼 구성",
    "version": "1.0",
    "createdAt": "2026-03-15T09:00:00.000",
    "table": "orders"
  },
  "structures": {
    "price": {
      "mainColumnName": "price",
      "displayName": "단가·수량",
      "lines": [
        { "prefix": "",        "columnName": "price" },
        { "prefix": "→ 수량: ", "columnName": "qty" }
      ]
    }
  }
}
```

---

### 7.2 전체 서버 내보내기

앱에 저장된 **모든 서버·데이터베이스·테이블**의 구조를 하나의 파일로 내보냅니다.

메타데이터 입력 후 **항목 선택** 화면이 표시됩니다.

```
포함할 항목
[전체 선택]  [전체 해제]
☑ mydb / orders          서버: 192.168.1.10  3개
☑ mydb / products        서버: 192.168.1.10  1개
☐ analytics / sales      서버: 192.168.1.20  2개
```

체크박스로 포함할 항목을 선택한 후 **[내보내기]** 를 누릅니다.

저장 파일명 기본값: `cell_structures_all.json`

**파일 구조**:
```json
{
  "formatVersion": "multi-table-1",
  "metadata": {
    "name": "전체 설정 백업",
    "version": "2.0",
    "createdAt": "2026-03-15T09:00:00.000",
    "table": ""
  },
  "entries": [
    {
      "server": "192.168.1.10:5432",
      "database": "mydb",
      "table": "orders",
      "structures": { ... }
    },
    {
      "server": "192.168.1.10:5432",
      "database": "mydb",
      "table": "products",
      "structures": { ... }
    }
  ]
}
```

## 8. 가져오기

목록 화면의 **[가져오기]** 버튼을 누르면 파일 선택기가 열립니다. `.json` 파일을 선택하면 파일 형식을 **자동으로 감지**해 적절한 가져오기 화면을 표시합니다.

---

### 8.1 현재 테이블 포맷 파일

`structures` 키가 있는 단일 테이블 포맷 파일은 **현재 테이블로 가져옵니다**.

미리보기 화면에서 파일 정보와 포함된 구조 목록을 확인합니다.

```
가져오기 미리보기
┌──────────────────────────────────┐
│ 이름: 고객 테이블 뷰 설정        │
│ 버전: 1.0                        │
│ 생성일: 2026-03-15 09:00         │
│ 테이블: orders                   │
└──────────────────────────────────┘
포함된 구조: 2개
✅ 단가·수량  ← price
⚠️ 고객명  ← customer_id   ← 현재 테이블에 없는 컬럼 포함

⚠️ 현재 테이블에 없는 컬럼: customer_id
   (해당 구조는 저장되지만 표시되지 않을 수 있음)

              [취소]  [가져오기]
```

| 아이콘 | 의미 |
|--------|------|
| ✅ | 모든 컬럼이 현재 테이블에 존재 |
| ⚠️ | 일부 컬럼이 현재 테이블에 없음 |

기존 구조와 **병합**됩니다. 같은 컬럼 이름의 구조는 덮어씁니다.

---

### 8.2 전체 서버 포맷 파일

`formatVersion: "multi-table-1"` 또는 `entries` 키가 있는 전체 서버 포맷 파일은 **항목 선택 화면**을 표시합니다.

```
전체 서버 가져오기
┌──────────────────────────────────┐
│ 이름: 전체 설정 백업             │
│ 버전: 2.0                        │
│ 생성일: 2026-03-15 09:00         │
└──────────────────────────────────┘
포함된 항목: 3개         [전체 선택]  [전체 해제]
☑ mydb / orders          서버: 192.168.1.10  3개
☑ mydb / products        서버: 192.168.1.10  1개
☐ analytics / sales      서버: 192.168.1.20  2개

ℹ️ 기존 설정에 덮어씁니다.
   다음에 해당 테이블을 열 때 적용됩니다.

              [취소]  [가져오기]
```

선택한 항목만 가져옵니다. **해당 서버·데이터베이스·테이블의 기존 구조를 덮어씁니다.**

> 가져온 구조는 **다음에 그 테이블을 열 때** 자동으로 적용됩니다. 현재 열려 있는 테이블에는 즉시 반영되지 않습니다.

---

## 9. 파일 포맷 명세

### 현재 테이블 포맷 (`cell_structures_{table}.json`)

```json
{
  "metadata": {
    "name": "string (필수)",
    "description": "string (선택)",
    "version": "string (기본: \"1.0\")",
    "createdAt": "ISO 8601 datetime",
    "table": "string (테이블명)"
  },
  "structures": {
    "{메인컬럼명}": {
      "mainColumnName": "string",
      "displayName": "string (선택, 헤더 표시 이름)",
      "lines": [
        {
          "prefix": "string (앞 텍스트, 빈 문자열 허용)",
          "columnName": "string"
        }
      ]
    }
  }
}
```

### 전체 서버 포맷 (`cell_structures_all.json`)

```json
{
  "formatVersion": "multi-table-1",
  "metadata": {
    "name": "string",
    "description": "string (선택)",
    "version": "string",
    "createdAt": "ISO 8601 datetime",
    "table": ""
  },
  "entries": [
    {
      "server": "string (서버 주소:포트)",
      "database": "string",
      "table": "string",
      "structures": {
        "{메인컬럼명}": { ... }
      }
    }
  ]
}
```

### 구 포맷 호환

`metadata` 없이 최상위가 바로 `structures` 맵인 구 포맷 파일도 가져올 수 있습니다.

---

## 10. 사용 예시

### 예시 1: 주문 테이블 — 단가와 수량을 한 셀에 표시

**목표**: `price` 컬럼 위치에 단가와 수량을 두 줄로 표시하고, 헤더를 "단가/수량"으로 변경.

1. 다이얼로그 열기 → `price` 컬럼 탭
2. **헤더 표시 이름** 입력: `단가/수량`
3. **직접 구성** 탭
   - 줄 1: 앞 텍스트 `""`, 컬럼 `price`
   - 줄 2: 앞 텍스트 `"수량: "`, 컬럼 `qty`
4. **저장**

**결과**:

| 단가/수량 ← price | customer_id | created_at |
|-------------------|-------------|------------|
| 15,000            | C001        | 2026-01-01 |
| 수량: 40          |             |            |

> `qty` 컬럼은 숨겨집니다.

---

### 예시 2: 고객명 컬럼 헤더 한글로 변경

**목표**: `customer_name` 컬럼 헤더만 "고객명"으로 표시.

1. `customer_name` 컬럼 탭
2. **헤더 표시 이름** 입력: `고객명`
3. **직접 구성** 탭 — 줄 1은 그대로 (`""` + `customer_name`)
4. **저장**

---

### 예시 3: 예시로 입력 탭을 활용한 빠른 설정

**목표**: `price`, `qty`, `unit`의 샘플 데이터를 붙여넣어 자동으로 구조 생성.

1. `price` 컬럼 탭 → **예시로 입력** 탭 선택
2. **① 샘플 값 입력**에 입력:
   ```
   price = 15000
   qty = 40
   unit = EA
   ```
3. **② 원하는 출력 형태**에 입력:
   ```
   15000
   수량: 40
   EA
   ```
4. 추론 결과 확인 → 메인 컬럼 `price` 선택
5. **저장**

---

### 예시 4: 설정 팀 간 공유

1. A 팀이 설정 완료 후 **[내보내기]** → **전체 서버** → 모든 항목 선택 → `설정_v1.json` 저장
2. B 팀이 앱에서 **[가져오기]** → `설정_v1.json` 선택 → 필요한 항목만 체크 → **[가져오기]**
3. B 팀이 해당 테이블을 열면 설정 자동 적용

---

## 설정 저장 위치

셀 구조 설정은 앱 내부 저장소(SharedPreferences)에 다음 키 형식으로 저장됩니다.

```
cell_structures|{서버주소}|{데이터베이스}|{테이블}
```

**예**:
```
cell_structures|192.168.1.10:5432|mydb|orders
```

서버·데이터베이스·테이블이 다르면 독립된 설정으로 관리됩니다.
