# 프로젝트 문서: dbHandler

## 1. 프로젝트 개요

`dbHandler`는 다양한 데이터베이스를 관리하고 상호 작용하도록 설계된 Flutter 애플리케이션입니다. 사용자는 여러 데이터베이스 서버에 연결하고, 데이터베이스와 테이블을 관리하며, 데이터를 편집할 수 있습니다. 이 프로젝트는 BLoC, MobX, Riverpod, GetX 등 Flutter의 다양한 상태 관리 솔루션을 시험하는 테스트베드 역할을 합니다.

## 2. 프로젝트 구조

이 프로젝트는 표준 Flutter 프로젝트 구조를 따릅니다. 핵심 애플리케이션 로직은 `lib` 디렉터리에 있습니다.

-   `lib/`: 애플리케이션의 기본 소스 코드를 포함합니다.
    -   `main.dart`: 애플리케이션의 진입점입니다. 앱을 초기화하고, 상태 관리 프로바이더를 설정하며, 라우트를 정의합니다.
    -   `db/`: 데이터베이스 처리 로직을 포함합니다.
        -   `database_handler.dart`: 모든 데이터베이스 작업을 위한 인터페이스를 정의하는 추상 클래스입니다.
        -   `postgres_handler.dart`: PostgreSQL용 `DatabaseHandler`의 구현체입니다.
    -   `l10n/`: 현지화 파일(`.arb` 파일)과 번역을 처리하기 위한 `LocalizationManager`를 포함합니다.
    -   `sqflite/`: 로컬 SQLite 데이터베이스 로직을 포함합니다.
        -   `database.dart`: 로컬 SQLite 데이터베이스 연결 및 스키마를 관리합니다.
        -   `models/`: `ServerModel`과 같은 데이터 모델을 포함합니다.
    -   `stateManagement/`: 다양한 상태 관리 솔루션의 구현을 포함합니다.
        -   `bloc/`: BLoC 패턴 구현.
        -   `getx/`: GetX 상태 관리.
        -   `mobx/`: MobX 상태 관리.
        -   `setState/`: Riverpod와 함께 `setState`를 사용한 상태 관리.
    -   `views/`: 애플리케이션의 UI 구성 요소(화면 및 위젯)를 포함합니다.
-   `assets/`: JSON 파일과 같은 정적 자산을 포함합니다.
-   `test/`: 애플리케이션 테스트를 포함합니다.
-   `TODO.txt`, `QA_todo.txt`: 프로젝트의 할 일 목록과 품질 보증 체크리스트를 포함합니다.

## 3. 기능

-   **서버 관리:**
    -   데이터베이스 서버 연결 추가, 편집 및 삭제.
    -   PostgreSQL 서버를 지원합니다.
    -   서버 연결 정보(자격 증명 및 키 파일 포함)를 로컬 SQLite 데이터베이스에 안전하게 저장합니다.
-   **데이터베이스 관리:**
    -   연결된 서버의 데이터베이스 목록 보기.
    -   데이터베이스 생성, 이름 변경 및 삭제.
-   **테이블 관리:**
    -   선택한 데이터베이스의 테이블 목록 보기.
    -   테이블 생성, 이름 변경 및 삭제.
-   **데이터 관리:**
    -   테이블 내 데이터 보기 및 편집.
-   **설정:**
    -   언어 및 테마 변경.
    -   즐겨찾기 관리.
    -   설정 백업 및 복원.
    -   모든 설정 초기화.

## 4. 사용자 흐름

1.  **스플래시 화면:** 애플리케이션은 필요한 구성 요소를 초기화하는 스플래시 화면으로 시작됩니다.
2.  **서버 선택:** 사용자에게 저장된 서버 연결 목록이 표시됩니다. 서버를 추가, 편집 또는 삭제할 수 있습니다. 서버에 연결하려면 해당 서버를 탭합니다.
3.  **데이터베이스 선택:** 서버에 연결한 후 사용자는 해당 서버의 데이터베이스 목록을 봅니다. 데이터베이스를 생성, 이름 변경 또는 삭제할 수 있습니다. 데이터베이스로 작업하려면 해당 데이터베이스를 탭합니다.
4.  **테이블 선택:** 데이터베이스를 선택한 후 사용자는 해당 데이터베이스의 테이블 목록을 봅니다. 테이블을 생성, 이름 변경 또는 삭제할 수 있습니다. 테이블의 데이터를 보려면 해당 테이블을 탭합니다.
5.  **데이터 편집:** 테이블을 선택한 후 사용자는 해당 테이블의 데이터를 보고 편집할 수 있습니다.

## 5. 상태 관리

이 애플리케이션은 여러 상태 관리 솔루션을 사용하도록 구성되어 있으며, 이를 통해 Flutter 앱에 통합하는 방법을 보여줍니다.

-   **Riverpod:** 최상위 종속성 주입 솔루션(`ProviderScope`)으로 사용됩니다.
-   **Provider:** MobX 저장소 및 BLoC 블록의 인스턴스를 위젯 트리에 제공하는 데 사용됩니다.
-   **MobX:** `ServerSelectionScreen`에서 상태 관리에 사용됩니다. `ServerStore` 클래스는 서버 목록과 추가/편집 서버 양식의 상태를 관리합니다.
-   **BLoC:** `SettingsBloc`을 통해 애플리케이션의 전반적인 설정을 관리합니다. 이는 싱글턴으로 구현되어 앱의 어느 곳에서나 일관된 설정 상태를 유지합니다. UI는 `StreamBuilder`를 통해 BLoC의 상태 변화를 실시간으로 반영합니다.

## 6. 데이터베이스

이 애플리케이션은 두 가지 유형의 데이터베이스를 사용합니다.

-   **로컬 SQLite 데이터베이스:** 로컬 SQLite 데이터베이스는 서버 연결 목록과 해당 설정을 저장하는 데 사용됩니다. 이를 위해 `sqflite` 패키지가 사용됩니다.
-   **원격 데이터베이스(PostgreSQL):** 이 애플리케이션은 원격 PostgreSQL 데이터베이스에 연결할 수 있습니다. `postgres` 패키지는 PostgreSQL 서버와 통신하는 데 사용됩니다. `PostgresHandler` 클래스는 `DatabaseHandler` 인터페이스를 구현하고 모든 PostgreSQL 관련 작업에 대한 로직을 포함합니다.

## 7. 설정 및 구성

애플리케이션의 설정은 `SettingsBloc`을 통해 중앙에서 관리되며, `shared_preferences`를 통해 디바이스에 영구적으로 저장됩니다.

-   **언어 및 테마:** 사용자는 앱의 언어(영어, 한국어)와 테마(시스템, 라이트, 다크)를 변경할 수 있습니다.
-   **즐겨찾기:** 자주 사용하는 서버, 데이터베이스, 테이블을 즐겨찾기로 등록하여 빠르게 접근할 수 있습니다.
-   **백업 및 복원:** 모든 앱 설정을 JSON 파일로 내보내거나, 파일로부터 설정을 가져와 복원할 수 있습니다.
-   **데이터 초기화:** '위험 구역'에서 모든 설정을 초기화하는 기능을 제공합니다.
-   **테이블별 설정:** 테이블별로 필터 및 컬럼 순서를 저장하여 사용자 경험을 개인화합니다.
