Master에 pr할 때마다 확인할 목록

전체
- 누락된 메소드 주석 추가
- 사용하지 않는 메소드 및 코드 제거
- 모든 warning 수정
- 번역되지 않은 텍스트 처리

ServerSelection
- 서버 추가 및 삭제
- 서버 정보 수정
- 중복 서버 추가 시도

DatabaseSelection
- 데이터베이스 추가 및 삭제
- 데이터베이스 정보 수정
- 이미 저장된 이름의 데이터베이스 생성 시도

TableSelection
- 테이블 추가 및 삭제
- 테이블 이름 변경
- 이미 저장된 이름의 테이블 생성 시도

DataEditing
- 값 수정
- 셀 한 개, 셀 여러 개 복사 및 붙여넣기
- 행, 열 추가 및 삭제
- filter 문법 확인
- filter, sort, groupBy 적용
- 컬럼 제약 조건, 데이터 타입 변경
