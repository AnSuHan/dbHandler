# 📋 다중 테이블 뷰(Multi-Table View) UI 기획안

이 문서는 사용자가 데이터베이스 내의 여러 테이블을 동시에 확인하고, 데이터를 비교하거나 관리하기 위한 UI 개선 방향을 제안합니다.

---

## 1. 개요
현재의 리스트 방식은 테이블 수가 많아질수록 한눈에 파악하기 어렵고, 여러 테이블의 데이터를 교차 확인하려면 화면을 계속 이동해야 하는 불편함이 있습니다. 이를 해결하기 위해 **대시보드형 그리드 뷰**와 **탭 기반 워크스페이스** 구성을 제안합니다.

---

## 2. 주요 UI 구성 요소

### 2.1 대시보드형 그리드 뷰 (Grid Dashboard)
- **목적**: 데이터베이스 전체 상태(테이블별 규모 및 구조)를 한눈에 파악.
- **상세 설계**:
    - **카드 레이아웃**: 기존 리스트 항목을 2~3열 그리드 카드로 변경.
    - **시각적 메트릭**: 행(Row) 개수와 컬럼(Column) 수를 게이지나 바 형태의 인디케이터로 표시하여 데이터 규모를 직관적으로 비교.
    - **퀵 프리뷰**: 카드 내에 상위 5개 행의 데이터를 작게 보여주는 미니 테이블 포함.

### 2.2 탭 기반 멀티 워크스페이스 (Tabbed Workspace)
- **목적**: 여러 테이블의 데이터를 열어두고 빠르게 전환하며 작업.
- **상세 설계**:
    - **상단 탭 바**: 크롬 브라우저처럼 상단에 선택한 테이블들을 탭으로 나열.
    - **상태 유지**: 탭 전환 시 각 테이블의 필터링, 정렬 상태를 메모리에 유지하여 작업 흐름 보존.
    - **탭 분할(Split View)**: 화면을 좌우/상하로 분할하여 두 개 이상의 테이블 데이터를 동시에 대조 가능.

### 2.3 스키마 기반 그룹화 (Schema Grouping)
- **목적**: 복잡한 데이터베이스 구조를 체계적으로 분류.
- **상세 설계**:
    - **아코디언 UI**: `public`, `auth`, `logging` 등 스키마별로 섹션을 나누어 접고 펼칠 수 있도록 구성.
    - **그룹 통계**: 스키마 그룹 헤더에 해당 그룹 내 전체 테이블 수와 합계 행 개수 표시.

---

## 3. 인터랙션 디자인

### 3.1 다중 선택 및 일괄 작업 (Bulk Selection)
- 각 테이블 카드/리스트에 체크박스 도입.
- 여러 테이블 선택 시 하단에 **일괄 작업 바(Bulk Action Bar)** 노출.
    - 선택한 테이블 일괄 내보내기 (CSV, JSON).
    - 선택한 테이블 일괄 삭제 (보안 확인 포함).
    - 선택한 테이블 간 조인(Join) 쿼리 생성기 실행.

### 3.2 실시간 필터 및 검색
- **통합 검색바**: 테이블명뿐만 아니라 컬럼명으로도 테이블을 검색하는 기능.
- **정렬 필터**: '데이터 많은 순', '최근 수정순', '컬럼 많은 순' 등 동적 정렬 옵션 제공.

---

## 4. 기대 효과
1. **작업 효율 향상**: 화면 전환 횟수를 70% 이상 감소시켜 데이터 탐색 시간 단축.
2. **비교 분석 용이**: 서로 연관된 테이블(예: User와 Order)을 한 화면에 띄워 데이터 정합성 확인 용이.
3. **가시성 확보**: 데이터베이스의 전체적인 규모와 부하를 시각적으로 즉시 파악 가능.

---

## 5. 추후 구현 고려사항 (Technical Hints)
- **상태 관리**: GetX 또는 BLoC을 사용하여 개별 탭의 상태(Paging, Filter)를 독립적으로 관리.
- **렌더링 최적화**: 다중 테이블 렌더링 시 메모리 부하를 줄이기 위해 `IndexedStack` 또는 `Offstage` 활용.
- **반응형 대응**: 화면 너비에 따라 그리드 열 수를 동적으로 조정(Desktop은 3열, Mobile은 1열).
