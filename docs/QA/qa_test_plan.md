# QA 테스트 계획서 (QA Test Plan)

이 문서는 `dbHandler` 프로젝트의 품질 보증을 위한 테스트 항목을 정리한 것입니다. Master 브랜치 병합(PR) 전 반드시 아래 항목들을 체크해야 합니다.

## 1. 공통 코드 품질 (General Code Quality)
- [ ] **주석 확인:** 모든 클래스 및 주요 메소드에 설명 주석이 포함되었는가?
- [ ] **코드 정리:** 사용하지 않는 import, 변수, 메소드 및 불필요한 코드가 제거되었는가?
- [ ] **경고(Warning) 수정:** `analysis_options.yaml` 기준 모든 lint 경고가 해결되었는가?
- [ ] **로그 제거:** 디버깅을 위해 추가한 `print`나 로그가 제거되었는가?

## 2. 화면별 기능 테스트 (Functional Testing)

### 2.1 서버 선택 화면 (Server Selection)
- [ ] **서버 추가/삭제:** 새로운 PostgreSQL 서버 정보를 입력하여 추가하고, 목록에서 정상적으로 삭제되는가?
- [ ] **서버 정보 수정:** 기존 서버의 이름, 호스트, 포트 등을 수정했을 때 반영되는가?
- [ ] **중복 검사:** 이미 등록된 이름이나 동일한 연결 정보로 중복 추가 시 적절한 안내가 표시되는가?
- [ ] **연결 테스트:** 잘못된 정보를 입력했을 때 연결 실패 메시지가 정확히 노출되는가?

### 2.2 데이터베이스 선택 화면 (Database Selection)
- [ ] **목록 조회:** 서버 연결 후 해당 서버의 데이터베이스 목록이 올바르게 로드되는가?
- [ ] **DB 생성/삭제:** 새로운 데이터베이스를 생성하고, 기존 데이터베이스를 삭제할 수 있는가?
- [ ] **이름 변경:** 데이터베이스 이름을 변경할 수 있으며, 변경 후 목록에 즉시 반영되는가?
- [ ] **중복 이름:** 이미 존재하는 이름으로 데이터베이스 생성 시도 시 에러 처리가 되는가?

### 2.3 테이블 선택 화면 (Table Selection)
- [ ] **목록 조회:** 선택한 DB 내의 테이블 목록이 누락 없이 표시되는가?
- [ ] **테이블 생성/삭제:** 테이블 생성 및 삭제 기능이 정상 작동하는가?
- [ ] **이름 변경:** 테이블 이름을 수정할 수 있는가?
- [ ] **중복 이름:** 기존 테이블과 겹치는 이름으로 생성/변경 시도 시 차단되는가?

### 2.4 데이터 편집 화면 (Data Editing)
- [ ] **값 수정:** 셀의 데이터를 수정하고 DB에 정상적으로 반영되는가?
- [ ] **복사/붙여넣기:**
    - [ ] 단일 셀 복사 및 붙여넣기
    - [ ] 여러 셀(영역) 복사 및 붙여넣기
- [ ] **행/열 조작:** 행(Row) 추가/삭제, 열(Column) 추가/삭제 기능 확인
- [ ] **필터(Filter):**
    - [ ] 필터 문법(`(A) and B` 등)이 정상적으로 파싱되고 적용되는가?
    - [ ] 복합 조건 필터링 결과가 정확한가?
- [ ] **정렬 및 그룹화 (Sort & GroupBy):**
    - [ ] 특정 컬럼 기준 오름차순/내림차순 정렬
    - [ ] 그룹화 적용 시 데이터가 올바르게 묶이는가?
    - [ ] 정렬/그룹 순서 변경(드래그 앤 드롭 등)이 정상 작동하는가?
- [ ] **스키마 변경:** 컬럼의 제약 조건(Nullable, Unique 등)이나 데이터 타입을 변경했을 때 DB에 반영되는가?

## 3. 상태 관리 및 환경 설정 (State & Settings)
- [ ] **상태 유지:** 화면 전환 시(Selection -> Editing -> Selection) 이전 상태(필터, 정렬 등)가 적절히 유지되는가?
- [ ] **테마 적용:** 라이트/다크 모드 전환 시 UI 요소의 가독성이 확보되는가? (특히 다크모드 색상)
- [ ] **설정 백업/복원:** 설정 정보를 JSON으로 내보내고 다시 가져왔을 때 서버 목록 및 앱 설정이 복구되는가?
- [ ] **초기화:** '위험 구역'에서 모든 데이터 초기화 시 앱이 깨끗한 상태로 돌아가는가?

## 4. UI/UX 및 현지화 (Localization)
- [ ] **언어 전환:** 영어 <-> 한국어 전환 시 모든 텍스트(다이얼로그, 툴팁 포함)가 번역되어 출력되는가?
- [ ] **반응형 레이아웃:** 창 크기 조절 시 UI가 깨지지 않고 적절히 배치되는가?
- [ ] **사용자 피드백:** 작업 성공/실패 시 SnackBar나 Dialog가 적절한 위치(특히 설정창 위)에 노출되는가?
- [ ] **입력 제어:** 키보드가 없는 환경을 고려한 더블클릭/롱클릭 조작이 원활한가? (필터 등)
